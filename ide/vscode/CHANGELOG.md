# Changelog

## 0.1.0

- First public Host: catalog, search, file-format filter, composed selection, gzip export, restore, Agent Contract, filetree, and code graph without installing Python.
- **AI Context** is one export-first panel (search → format → Export → files → options → last export). Restricted Mode cannot write files.
- gzip is the default transport and writes `baic_prompt.md`.
- Oversized files stay unchecked until you check them; then they are included in the export.
