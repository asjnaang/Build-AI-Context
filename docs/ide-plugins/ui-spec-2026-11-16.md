# Build AI Context IDE UI

Visual reference: [ui-mockup.html](ui-mockup.html). This specifies the VS Code Activity Bar view and Android Studio tool window. The mockup is a layout reference.

Android Studio implements the layout with native Swing in the **AI Context** tool window. VS Code implements the same order in a themed `WebviewView` (`baic.panel`) using `--vscode-*` tokens. TreeView cannot host inline search, a format dropdown, and a full-width **Export** button in one panel. That webview is a persistent export-first panel, not a CLI-wizard webview.

## Primary flow

1. Opening **AI Context** catalogs the trusted project in the background. The file tree shows supported files checked by default; oversized files start unchecked with a size warning. No Scan step is required.
2. **Search files** matches relative path, filename, or category. **File format** narrows those results by extension (`.kt`, `.py`, and so on); **All formats** removes this filter. The tree and selected count reflect both filters. **Select all results** checks every result, including large files. Editing search/format does not erase earlier checks; clearing the filters reveals them again.
3. The header always shows the result count, selected count, current transport, and **Export**. Export uses checked files in the current search/format results. When the catalog is still loading, Export queues the operation. When nothing is checked, Export explains why.
4. A small **Selection** area has the checkable tree and category choices. Existing content-keyword and path selectors remain in **Options**. **Last export** reveals the output, manifest, and `baic_prompt.md`.
5. **Restore gzip** and **Refresh catalog** are secondary actions. Success shows the output path and ways to open the folder and prompt.

## CLI mapping and defaults

| CLI habit | IDE control | Behavior |
| --- | --- | --- |
| `baica` / `--all` | All supported / default checked tree | Select all normally discovered supported files. |
| `baicp`, `baicf`, `--paths` | Paths field, Add to AI Context context menu | Add explicit files or folders; combine with ignored and format overrides when needed. |
| `baick`, `--keywords` | Keywords field | Narrow selection to matching content. |
| Quick file search | Search files | Match names, paths, and category names in the catalog. |
| Format narrowing | File format | Intersect search results with one extension; Select all results checks the intersection. |
| `--categories` | Category checkboxes/toggles | Narrow by source category. |
| `--exclude-paths` | Exclude paths | Remove matching paths from final selection. |
| `--force-ignored` | Include ignored paths | Applies to explicitly named paths only. |
| `--force-include-formats` | Extra formats | gzip only. |
| `--force-bundle`, `--max-file-lines` | Include large files / line limit | Large files remain visibly flagged. |
| `--transport`, `--split` | gzip/text selector, Split gzip | gzip is default; text is readable bundles. |
| `--redact`, `--include-secret-files` | Safety options | Redact requires text. Secret-like files require confirmation. |
| `--project-overview`, `--graph`, `--tree` | Output options and standalone commands | Filetree is included in exports; optional graph/overview and standalone commands remain. |
| `--output-dir`, `--task` | Output folder and task in settings | Export writes transport-specific `baic_prompt.md`. |
| `--restore` | Restore gzip | Pick export source and destination. |

Default output is a timestamped export under the project unless a folder is set. The sample playthrough explicitly sets an output folder outside sample trees and disables gitignore updates.

## Layout and icon

At the observed 250–350 px panel width, **Search files**, **File format**, result count, and **Export** must remain visible above the tree. The file tree gets remaining height. Options are grouped by Selection, Package, and Safety/Output, with human labels before CLI spellings. The icon is one common 24-unit mark for both IDEs: a document frame, three context lines, and a small outward arrow. Its light and dark variants preserve contrast. Use native IDE controls, keyboard focus, tooltips, and theme colors.

## Acceptance

- At 250–350 px panel width, Export, search, format, result count, transport, and the checkable files remain readable without horizontal scrolling.
- Search plus `.kt` (or another present format) shows only that intersection; Select all results checks it; Export includes only checked files in the current results. Clearing search/format reveals prior checks.
- A user can reproduce the listed aliases by controls in the panel/settings and perform gzip Export without a separate Scan action.
- Both installed Hosts write a gzip manifest with `transport.format = tar+gzip+base64`, `baic_prompt.md`, and restorable source bytes in a chosen output folder.
- Host tests cover panel order and copy. Live window screenshots after install remain a human check.
